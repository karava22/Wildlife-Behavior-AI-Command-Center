# 🐾 Behavioural Recognition of Wildlife Animals using CNN

## 📌 Project Overview  
This project focuses on recognizing wildlife animal behavior in unstructured environments using Convolutional Neural Networks (CNN). The system analyzes images and video frames to detect animals and classify their behaviors such as walking, eating, or resting. It helps in wildlife monitoring, conservation, and research.

## 🚀 Live Demo  
👉 https://wildlife-behavior-ai-command-center-6unzuzcrp2dcsjrrpgwzn7.streamlit.app/

## 🎯 Features  
- Automatic wildlife animal detection  
- Behavior classification using CNN  
- Works in unstructured environments  
- Handles variations like lighting and background  
- Image preprocessing for better accuracy  
- Generates results for analysis  
- User-friendly interface using Streamlit
